# 🦥 Lazy Worker – RAV Bewerbungen Helper

Chrome-Erweiterung für Stellensuchende in der Schweiz: erfasst Bewerbungen automatisch und füllt das RAV-Formular "Nachweis der persönlichen Arbeitsbemühungen" mit einem Klick aus.

Dieses Repository enthält nur die Downloads. Mehr Infos: [philstranger.com](https://philstranger.com)

> **Update von einer älteren Version (deine Bewerbungen bleiben erhalten):**
> 1. Neue ZIP herunterladen und entpacken
> 2. Den **Inhalt** des neuen Ordners in deinen **bisherigen** Lazy-Worker-Ordner kopieren und "Ersetzen" wählen
> 3. In `chrome://extensions` bei Lazy Worker auf den runden Pfeil (**Neu laden**) klicken
>
> Lädst du stattdessen einen neuen Ordner, ist die Liste leer. Sichere dann vorher deine Bewerbungen als CSV (Download-Button im Popup).

## Installation (Schritt-für-Schritt)

> Du brauchst keine Programmierkenntnisse! Folge einfach diesen Schritten:

### Schritt 1: Herunterladen

Klicke auf den grossen Button unten — die Datei wird automatisch heruntergeladen:

### **[>>> Lazy Worker herunterladen <<<](https://github.com/Val313-313/lazy-worker-download/releases/latest/download/Lazy-Worker.zip)**

Es wird eine Datei namens `Lazy-Worker.zip` in deinen Downloads-Ordner gespeichert.

> **⚠️ Chrome blockiert den Download?**
> Chrome stuft ZIP-Dateien von neuen GitHub-Repos manchmal als "nicht sicher" ein. Das ist ein Fehlalarm — die Datei ist sicher.
>
> **So gehts trotzdem:**
> 1. Klicke auf den Download-Link oben
> 2. Unten links erscheint eine Warnung — klicke auf **"⌃"** (Pfeil) oder **"Mehr anzeigen"**
> 3. Wähle **"Behalten"** bzw. **"Trotzdem herunterladen"**
>
> Alternativ: Rechtsklick → **"Ziel speichern unter..."** funktioniert ebenfalls.
### Schritt 2: ZIP-Datei entpacken

- **Mac:** Doppelklicke auf die `.zip`-Datei im Finder — es entsteht ein Ordner namens `Lazy-Worker-v...`
- **Windows:** Rechtsklick auf die `.zip`-Datei → **"Alle extrahieren..."** → **"Extrahieren"** bestätigen

> Der entpackte Ordner heisst z.B. `Lazy-Worker-v1.0.5` (je nach Version). Merke dir, wo er liegt — du brauchst ihn gleich.

### Schritt 3: Erweiterungsseite in Chrome öffnen

Es gibt **zwei Wege**, um die Erweiterungsverwaltung zu öffnen:

**Weg 1 — über die Adressleiste:**
1. Öffne **Google Chrome**
2. Tippe oben in die Adressleiste: `chrome://extensions`
3. Drücke **Enter**

**Weg 2 — über das Menü:**
1. Klicke oben rechts auf die **drei Punkte** (⋮)
2. Gehe zu **Erweiterungen** → **Erweiterungen verwalten**

Du landest auf einer Seite mit dem Titel **"Erweiterungen"** (oder **"Extensions"**).

### Schritt 4: Entwicklermodus aktivieren

Oben rechts auf der Erweiterungsseite findest du einen Schalter:

- **Deutsch:** **"Entwicklermodus"**
- **Englisch:** **"Developer mode"**

Klicke darauf, sodass er **eingeschaltet** ist (blau). Es erscheinen drei neue Buttons oben links.

### Schritt 5: Erweiterung laden

1. Klicke oben links auf **"Entpackte Erweiterung laden"** (oder **"Load unpacked"**)
2. Es öffnet sich ein Datei-Auswahl-Fenster
3. Navigiere zu deinem **Downloads-Ordner** (oder wo du die ZIP entpackt hast)
4. **Wichtig:** Wähle den **ganzen Ordner** `Lazy-Worker-v...` aus — **nicht** die ZIP-Datei und **nicht** eine einzelne Datei im Ordner!
   - **Mac:** Klicke einmal auf den Ordner, dann auf **"Auswählen"**
   - **Windows:** Klicke einmal auf den Ordner, dann auf **"Ordner auswählen"**
5. Die Erweiterung erscheint jetzt in der Liste

> **Fehlermeldung?** Falls Chrome sagt *"manifest.json not found"*: Du hast wahrscheinlich den falschen Ordner gewählt. Stelle sicher, dass du den Ordner `Lazy-Worker-v...` direkt auswählst (nicht einen Unterordner oder die ZIP-Datei selbst).

### Fertig!

Du siehst jetzt das 🦥 Lazy Worker Icon oben rechts in Chrome. Die Erweiterung ist installiert und einsatzbereit!

> **Tipp:** Wenn das Icon nicht sichtbar ist, klicke auf das **Puzzle-Symbol** (🧩) oben rechts in Chrome und pinne "Lazy Worker" an.
